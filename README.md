# Finca La Sevillana — Archic prototype

Prototipo comercial para **Finca La Sevillana (Écija)**. El objetivo no es hacer una landing genérica, sino enseñar cómo una presencia digital propia puede convertir búsquedas de bodas y eventos en solicitudes estructuradas.

## Qué incluye

- Web responsive con dirección visual editorial/premium.
- Información pública del espacio: salón climatizado, hasta 400 comensales, jardines, parking privado y posibilidad de elegir catering.
- Conversión a WhatsApp con mensaje estructurado desde el formulario.
- Ubicación mediante Google Maps.
- SEO local básico + Schema.org `EventVenue`.
- Owner Studio de demostración en `/studio.html` con solicitudes, calendario y CRM conceptual.
- `robots.txt`, `sitemap.xml`, favicon y cabeceras de seguridad para Vercel.

## Importante antes de producción

Las fotografías utilizadas en la demo son **fotografías de ambiente con licencia Unsplash**, no fotografías de Finca La Sevillana. Para una presentación final o una web real deberían sustituirse por material original del negocio y reportajes reales de sus celebraciones.

También debe confirmarse con la propiedad que los datos públicos siguen vigentes (capacidad, condiciones de catering, teléfono y dirección) antes de publicar como web oficial.
